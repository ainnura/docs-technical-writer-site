# Setting Up a Local Development Environment

This guide walks you through setting up Taskify locally for development and testing.

### Prerequisites
Make sure you have the following installed:
- Node.js (v18 or higher)
- PostgreSQL
- Git

### Installation Steps
```bash
git clone https://github.com/yourusername/taskify.git
cd taskify
npm install
npm run dev
