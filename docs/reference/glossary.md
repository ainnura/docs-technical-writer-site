# Glossary

This section defines key terms used throughout Taskify documentation.

| Term | Definition |
|------|-------------|
| **Workspace** | A shared space where teams organize and manage their projects and tasks. |
| **Task** | A work item that can be assigned to one or more users. Each task can have a title, description, deadline, and status. |
| **Board (Kanban)** | A visual board that displays tasks grouped by their current status — *To Do*, *In Progress*, and *Done*. |
| **Assignee** | A user responsible for completing a specific task. |
| **API** | Application Programming Interface — allows external systems or developers to interact with Taskify’s features programmatically. |
| **Token** | A unique string used to authenticate and authorize access to the Taskify API. |
| **PWA (Progressive Web App)** | A web application that can be installed and run like a native app on desktop or mobile devices. |
| **Microservices** | An architectural pattern where an application is divided into smaller, independent services that communicate through APIs. |
| **JWT (JSON Web Token)** | A secure token format used for user authentication in Taskify’s API. |
